Privacy policy

Last updated: 25 November 2026.

Pulso Zen is used only by its owner, on the owner's own YouTube channels.

  • With the owner's permission, it uses the YouTube Data API and YouTube Analytics API to upload videos, set thumbnails and schedules, and read the statistics of those same channels.
  • OAuth tokens are stored only on the owner's computer. No data is sold, shared with third parties or used for advertising.
  • No data from other users is collected.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Pulso Zen's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
